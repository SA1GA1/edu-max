# Контекст EDU

EDU создан для кейса «Образовательные решения» хакатона MAX. Продукт помогает подросткам 14–18 лет перейти от интереса к IT к первой публичной работе: выбрать направление, выполнить задание, приложить GitHub-репозиторий и найти команду.

## Пользовательский путь

1. Пользователь открывает мини-приложение из бота MAX.
2. Выбирает направление и уровень на интерактивной карте.
3. Берёт одно из трёх практических заданий, публикует ссылку на GitHub и получает результат проверки.
4. Видит рост XP и навыков, вступает в проект или публикует короткое видео.

## Границы MVP

Сервер хранит пользователей, прогресс, проекты, события, публикации и загруженные файлы. Проверка репозитория подготовлена как контракт: сейчас она создаёт проверку и возвращает результат, а отдельный сервис проверки можно подключить без изменения клиентского API.

## Метрики пилота

Проверяемые гипотезы пилота: не менее 60% новых пользователей выбирают направление, 40% берут первое задание и 25% завершают его за семь дней.
