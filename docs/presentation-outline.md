# Презентация EDU

Финальный PDF формируется для GitHub Release после создания тега, чтобы на первом слайде указать неизменяемый commit hash.

## 1. Технический доступ

Ссылка MAX, production URL, GitHub, commit hash, API, способ авторизации и короткий сценарий проверки.

## 2. EDU и команда

Название продукта, назначение и роли трёх участников.

## 3. Аудитория и проблема

Школьники 14–18 лет, которым сложно выбрать IT-направление и дойти до первой законченной работы. Формулировка обозначается как продуктовая гипотеза.

## 4. Пользовательский путь

Вход через MAX, выбор направления, задание, GitHub-проверка, XP и следующий уровень.

## 5. Учебная система

Шесть направлений, семь уровней, три задания на уровень, 126 практических работ.

## 6. Интерфейс

Актуальные экраны главной, задания и коротких видео.

## 7. Архитектура

MAX WebApp, React, Node.js API, SQLite, медиа и GitHub API. Сервер остаётся источником истины для XP и прав.

## 8. Пилот

Онлайн-сообщество в MAX. Целевые значения гипотезы: 60% выбирают направление, 40% принимают задание, 25% завершают его за семь дней.

## 9. Масштабирование

PostgreSQL, объектное хранилище, очередь проверок, модерация, кабинет наставника и редактор roadmap.

## 10. Ограничения и следующий шаг

Структурная проверка GitHub, отсутствие подтверждённых метрик пилота, локальное хранение видео. Следующий шаг — недельный пилот и измерение воронки.
