## Критерии демонстрации

1. Бот открывает mini app через MAX.
2. Пользователь видит шесть направлений и три задания на первом уровне.
3. Принятое задание появляется во вкладке «Мои задания» после перезапуска.
4. Публичный GitHub-репозиторий проходит базовую проверку.
5. XP начисляется один раз, следующий уровень открывается на сервере.
6. Дополнительные сценарии сохраняют проект, регистрацию, реакцию, комментарий и видео.

## Доказательства проверки

Перед релизом выполняются `npm test`, `npm run test:server`, `npm run build`, чистая Docker-сборка и запросы к production `/healthz` и защищённому API без авторизации.
