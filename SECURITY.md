# Безопасность

Сообщайте об уязвимостях владельцу репозитория через приватный канал GitHub. Не создавайте публичную задачу с токенами, персональными данными или способом обхода авторизации.

## Секреты

`MAX_BOT_TOKEN` и `GITHUB_TOKEN` хранятся только в окружении сервера. `.env`, SQLite и пользовательские медиа исключены из Git. Если токен попал в переписку, лог или историю Git, его нужно отозвать и заменить.

## Аутентификация

API принимает `Authorization: MaxInit <WebAppData>`, проверяет HMAC, уникальность параметров, пользователя и `auth_date`. Максимальный возраст данных — один час. Публичный тестовый обход не предусмотрен.

## Пользовательский контент

Аватары проверяются по сигнатуре и ограничены 5 МБ. Видео принимаются в MP4 или WebM до 100 МБ по одноразовой ссылке. GitHub-проверка не клонирует и не выполняет пользовательский код.
